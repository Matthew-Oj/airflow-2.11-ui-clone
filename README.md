# Airflow 2.11.2 UI Clone

A lightweight frontend clone inspired by the Apache Airflow 2.11.2 web UI.

## Features

- DAG listing interface
- DAG enable/disable toggles
- DAG owners, schedules, and run information
- Recent task status indicators
- Basic action controls
- Airflow-inspired navigation and styling

## Tech

- HTML
- CSS

## Run

Open `index.html` in your browser.

No build step or dependencies are required.
